1
Let é uma maneira de armazenar dados em uma variável, sempre utilizada quando for criar uma. Porque a própria linguagem associa e atribui ao tipo de valor, ex: inseri o número 10, ele vai definir como uma variável do tipo inteira.

2
O If/Else funciona como uma estrutura de condição, de tal modo que ele verifica se as especificações são verdadeiras ou falsas. o If é o primeiro à ser verificado, caso não seja, ele passa para o else if, se houver, seguido pelo else, que finaliza a estrutura. É uma condição que compara se o valor X é maior ou igual a um valor que vem após o ">=" Y.

3
A estrutura "for" significa enquanto tal condição não for atingida, o código dentro da estrutura irá repetir. "let i" é uma variável que define o início do laço de repetição, "i <= 20" define o final do laço de repetição, e "i++" acrescenta um valor à variável i, se não tiver finalizado o laço.

4
As funções servem para economizar trechos de código, que dentro delas tem uma função predefinida, de modo à tornar o código mais simples e prático. Return é o retorno da função, ou seja, a ação dela quando a função é chamada.

5
Class é uma definição de múltiplos atributos pertencentes a um mesmo objeto, por exemplo, uma pessoa tem nome, idade, cpf e etc. O constructor é responsável por definir os atributos de uma class. E o this serve para diferenciar o dado de outros dados similares que foram definidos antes, ou seja, fala para o código que aquele dado está sendo usado naquele instante. Por exemplo: "this.nome = nome;", como se fosse: esta variável recebe nome.
